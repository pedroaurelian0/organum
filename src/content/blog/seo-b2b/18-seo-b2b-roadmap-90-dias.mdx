SEO B2B sem roadmap é produção de conteúdo sem resultado.

A sequência importa mais que o volume de ações. Um plano de 90 dias bem estruturado entrega mais resultado do que um ano de execução desordenada.

Este é o roadmap de 12 semanas que a Organum executa para clientes B2B — baseado no caso real de uma empresa de consultoria B2B que saiu de 32 visitas orgânicas para 355 novos usuários mensais, com tráfego orgânico superando o pago no primeiro mês.

## Diagnóstico pré-roadmap (Semana 0)

Antes de executar qualquer ação, o diagnóstico precisa mapear o estado atual nas 5 camadas:

**Fundação Técnica:**
- PageSpeed Insights — Core Web Vitals aprovados ou reprovados?
- Screaming Frog — volume de erros 4xx e broken links
- Rich Results Test nas páginas principais — schemas válidos?
- Search Console — erros de cobertura, páginas excluídas

**Entidade:**
- Wikidata — existe? Campos completos?
- Knowledge Graph — painel ativo no Google?
- Schema Organization — sameAs configurado?

**Conteúdo:**
- Blog — volume de tráfego atual, quantidade de artigos
- Clusters existentes ou conteúdo avulso?
- E-E-A-T — autoria identificada, dados verificáveis?

**GEO:**
- Testar 5 queries prioritárias no ChatGPT, Gemini, Perplexity
- Empresa aparece? Concorrentes citados?

**Digital PR:**
- Perfil de backlinks — porcentagem de tóxicos
- Menções editoriais existentes

Com o diagnóstico completo, o roadmap é personalizado para os gaps identificados.

## Semanas 1-2 — Fundação Técnica

**S1 — Correções críticas de CWV**
- Implementar Defer JS para scripts de terceiros
- Corrigir CLS (font-display, dimensões de imagem)
- Implementar lazy load para embeds externos (formulários, maps)
- Adicionar preload para elemento LCP

**S1 — Schemas JSON-LD**
- Schema Organization com sameAs (Wikidata + LinkedIn + Glassdoor)
- Schema Person para o fundador/especialista principal
- Schema Service na página de serviço principal

**S2 — Correção de erros 4xx e broken links**
- Priorizar 4xx com backlinks externos → 301 para URL equivalente
- Corrigir broken links internos em páginas de alta autoridade
- Remover do sitemap URLs que retornam 4xx

**S2 — Canonical tags e on-page**
- Canonical em todas as páginas sem canonical declarado
- Title tags e meta descriptions revisadas nas páginas principais
- Sitemap XML atualizado e re-enviado ao Search Console

**Meta de S1-2:** Rich Results Test com 0 erros críticos. Core Web Vitals aprovados. Zero 4xx em páginas linkadas.

## Semanas 3-4 — Entidade + LP Pilar

**S3 — Wikidata e sameAs**
- Criar entrada Wikidata para a empresa (campos: instance of, industry, country, website, founders)
- Criar entradas Wikidata para fundadores se não existirem
- Atualizar Schema Organization com Wikidata Q-IDs

**S3 — LP Pilar Cluster 1**
- Publicar landing page pilar do cluster principal
- Schemas: Service + HowTo + FAQPage + Person
- Canonical correto, Rank Math configurado
- Solicitar indexação no Search Console

**S4 — Baseline GEO**
- Testar 5 queries no ChatGPT, Gemini, Perplexity
- Documentar: aparece? posição? concorrentes citados?
- Este é o baseline que será comparado no dia 90

**S4 — Disavow de backlinks tóxicos**
- Gerar arquivo disavow com domínios spam identificados no diagnóstico
- Enviar via Google Search Console

**Meta de S3-4:** LP pilar publicada e indexada. Wikidata criado. Baseline GEO documentado.

## Semanas 5-8 — Escala de Conteúdo

**S5-6 — Artigos satélite Cluster 1 (topo de funil)**
- Artigo 1: "O que é [serviço]?" — intent informacional, 2.000w
- Artigo 2: "Como funciona o processo de [serviço]?" — HowTo schema
- Artigo 3: "Diferença entre [serviço] e [alternativa]" — comparativo

Para cada artigo:
- Internal links obrigatórios: pilar + 1 satélite adjacente + 1 página de serviço
- Schema Article + FAQPage (7 Q&As)
- Validação Rich Results Test
- Indexação solicitada no Search Console

**S7-8 — LP Pilar Cluster 2 + artigos satélite Cluster 1 (meio de funil)**
- LP pilar do segundo cluster publicada
- Artigo 4: "Quando contratar [serviço]?" — intent de avaliação
- Artigo 5: "Etapas do processo de [serviço]" — HowTo schema

**Meta de S5-8:** 5 artigos publicados, 2 clusters com LP pilar. Tráfego orgânico em crescimento mensurável.

## Semanas 9-12 — GEO, Fundo de Funil e Digital PR

**S9-10 — Artigos de fundo de funil**
- Artigo 6: "Quanto custa [serviço]?" — intent transacional
- Artigo 7: "[Serviço] vs [alternativa]" — comparativo decisão
- Artigo 8: "Como contratar [serviço] para empresa" — intent de contratação

**S10-11 — Clusters 3 e 4 iniciados**
- LP pilares dos clusters 3 e 4 publicadas
- Primeiros artigos satélite dos clusters 3 e 4

**S11-12 — Digital PR**
- Pitches para 5 podcasts B2B do setor
- 1 guest post enviado para veículo relevante
- Pesquisa de mercado iniciada (link magnet para 2026)

**S12 — Re-teste GEO**
- Repetir as 5 queries do baseline GEO nas 3 IAs
- Comparar: empresa aparece agora? Em quais queries? Mais ou menos que os concorrentes?
- Ajustar estratégia de conteúdo baseado nos gaps identificados

## FAQ

**O roadmap de 90 dias é igual para todos os clientes B2B?**
A estrutura é a mesma, mas a execução é personalizada pelo diagnóstico. Um cliente com fundação técnica saudável avança mais rápido para conteúdo e GEO. Um cliente com 218 erros 4xx passa mais tempo nas primeiras semanas na Camada 1. O roadmap se adapta ao gap identificado no diagnóstico inicial.

**O que acontece depois dos 90 dias?**
Os 90 dias resolvem a fundação e publicam os primeiros clusters. A partir do dia 91, o trabalho é: escala de conteúdo (completar os 5 clusters), amadurecimento do GEO (aumentar citações nas IAs), Digital PR (construir perfil de backlinks) e monitoramento contínuo de KPIs. O SEO B2B maduro leva 12-18 meses.

**Preciso pausar o Google Ads enquanto faço SEO?**
Não. Os dois canais devem rodar em paralelo. O Ads gera pipeline imediato enquanto o SEO é construído. Os dados de conversão do Ads informam quais clusters e keywords priorizar no SEO. A meta de longo prazo é que o SEO reduza a dependência do Ads, não que o substitua abruptamente.

**Como saber se o roadmap está funcionando nas primeiras semanas?**
Nas primeiras 2 semanas, os sinais são técnicos: Core Web Vitals aprovados, Rich Results Test com 0 erros, 4xx reduzidos. O tráfego orgânico leva 4-8 semanas para reagir às correções técnicas. A posição de keywords novas leva 8-12 semanas. Não confundir ausência de sinal imediato com ausência de resultado — o SEO tem latência.

**Quanto de conteúdo precisa ser produzido nos 90 dias?**
O roadmap prevê 12 artigos em 90 dias — aproximadamente 1 por semana com semanas de folga para LP pilares e trabalho técnico. Cada artigo é de 2.000+ palavras com schemas válidos e internal linking correto. Volume sem qualidade não gera resultado; qualidade sem volume não cobre a jornada do ICP.
